## Starts cleanly while the TV certificate service is down

With `IPADDRESS` set, the server asks Stremio's certificate service for the trusted `*.stremio.rocks`
certificate at startup. When that service failed quickly, the container could stop during start and
restart over and over. It now starts every time: a trusted certificate it already has is kept for as
long as it is valid, and only a server with none falls back to a self-signed one until the service
is back (restart the container then).

**Upgrade:** pull it.
