# HDR stays bright when it is transcoded

When a player needed an HDR film transcoded, the picture came out grey and flat: it was converted to
SDR without adjusting its light levels.

- On a GPU that can tone-map HDR, transcoded HDR is now tone-mapped. The server checks this at
  startup and says so in its log; some GPUs accept the request and change nothing, and those are
  not used for it.
- Tone mapping on the CPU is available with `STREMIOSRV_TRANSCODE_CPU_TONEMAP=true`. It is off by
  default because a machine with few cores may not keep up, and the film would then stall.
- HDR that plays without a transcode is untouched.

**Upgrade:** pull it. Set `STREMIOSRV_TRANSCODE_CPU_TONEMAP=true` if your machine has CPU to spare
and its GPU cannot tone-map.
