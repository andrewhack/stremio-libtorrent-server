## Streams that need request headers play, and unknown paths fail loudly

**Playback** — the server now answers `/proxy`, which the Stremio player uses for any HTTP stream
whose addon says it needs particular request headers. Those streams could not play before. A
client on your own network can reach your LAN through it as well; a client from the internet, or a
web page on another site, only public addresses.

**Server** — a path the server does not implement now answers 404 instead of the web player's
page, and `/stats.json` counts each one by its shape (`unmatchedRoutes`), never by what it named.

**Web player** — the image now ships the file the player checks before using the server address
you configured; it used to find it only by accident.

**Upgrade:** pull it. Behind a reverse proxy, or when Docker forwards IPv6 clients into an
IPv4-only container, clients can look like they are on your own network: set
`STREMIOSRV_LIBRARY_ADDON_ALLOW` to your LAN ranges (see the README).
