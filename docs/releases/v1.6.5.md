## The library addon learns the titles you play

**Library addon** — the local-copy row appeared only for titles downloaded from the library page.
Anything that reached the box through ordinary playback had no row on its page, films and episodes
alike. The addon now learns a title the first time the app plays it, from any addon: the app reports
which file is playing, and a byte-exact match against the copy on disk records the title.

**Library UI** — titles learned this way keep their name and poster on the page.

**Upgrade:** pull it, then remove the addon in the app and add it again once — the app keeps the
capabilities it read at install time.
