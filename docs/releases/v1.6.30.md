## Subtitles for streams without a file index

A stream an addon gives without a file index plays as `/<infoHash>/-1`. For those streams the
OpenSubtitles hash now comes back (it was empty, so matching fell back to the file name), a TV's
styled embedded subtitles are found, and the per-stream subtitle routes answer instead of 404.

The embedded-subtitle list now numbers its tracks the way the extractor reads them, so picking a
track from a file with video and audio in front gets that track. A track that takes too long to
extract answers 504 rather than a server error.
