## The web player's core now arrives as application/wasm, compressed

The web player's WebAssembly core went out as `application/octet-stream`, so browsers warned in the
console and compiled it only after the whole 4.8 MB had arrived. It now comes as `application/wasm`,
which lets the browser compile it while it downloads, and gzip-compressed like the other web assets:
about 1.5 MB on the wire.

**Upgrade:** pull it.
