## A stream row describes the episode, not the whole pack

**Library addon** — a row offering one episode of a season pack printed the pack's total size: 24 GB
behind a 3.5 GB file. It now names the file and gives that file's size. Whole-torrent streams are
unchanged.

**Docs** — the README says where the row appears: at the bottom of the source list, in the app's own
addon order.

**Upgrade:** pull it. No configuration or route changes.
