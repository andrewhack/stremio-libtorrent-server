# Transcoded plays start on a torrent that has just begun

Before a play goes through the transcoder, the server checks the file's first bytes. On a torrent
that had only just started, that check waited for the file's first piece without asking for it, so
the piece came whenever the download happened to reach it. The play could fail after two minutes
while the library showed the file well under way.

- The check now asks for that piece first, and the play starts about as soon as it arrives.
- A torrent the server paused after finishing what it had been asked for (the next episode of a
  pack, say) is resumed for it.
