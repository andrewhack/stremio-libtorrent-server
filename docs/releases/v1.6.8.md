## The library addon stays quick while a download runs

**Library addon** — while the player was still filling a title, each request to the addon worked
out how much of the file had arrived by asking the disk where its holes are. On ZFS that check has
to flush the file first, so the addon answered more slowly the faster the download ran — hundreds
of milliseconds per request on a busy box — and it could, rarely, see a file as complete before it
was. For a file the torrent session is writing, the count now comes from the session; files
nothing is writing are still measured on disk.
