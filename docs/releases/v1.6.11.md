## The library finds every episode of a pack, and single-file releases

The library's Stremio addon offers "My Library" entries for what is on the server. A torrent the
server was not actively holding was listed by its folder, which says nothing about how the torrent
numbers its files, so an episode of a season pack got no entry, or one that could point at the
wrong file, and a release that is a single file could never be recognised. Each torrent's own file
list is now read from the data the server keeps for it: every complete episode of a pack gets its
entry, and a single-file release is recognised the first time it plays.
