## Intel/AMD hardware transcoding no longer fails on sources the GPU cannot decode

With an Intel or AMD GPU (VAAPI), a source its hardware decoder does not support — 10-bit HEVC on
older Intel graphics, AV1 before the decoder supports it — made the transcode fail, and the player
showed an error. Those sources are now decoded in software and still encoded on the GPU. Sources
the GPU can decode take the hardware path as before.

**Upgrade:** pull it.
