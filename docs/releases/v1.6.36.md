## Statistics match the stock server for streams without a file index

Since web player 5.0.0-beta.41, a stream that names no file asks the server for the torrent's
statistics instead of one file's. The server answered with a file progress of zero, so the player's
statistics showed "Completed 0 %" for the whole stream. It now leaves those per-file fields out, as
the stock server does, and the player hides the row.

**Upgrade:** pull it.
