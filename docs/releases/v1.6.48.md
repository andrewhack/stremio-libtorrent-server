# Matched to the stock server 4.22.3

The Windows desktop app now ships the stock streaming server 4.22.3. This server answers the way that
version does:

- A TV that draws styled subtitles itself can ask for the fonts after the subtitle tracks, through
  the new `/embedded-ass/fonts`.
- `/proxy` tells browsers never to guess a file's type, and hands an HTML page over as a download.
- The three public trackers stock added are in the default list.

**Upgrade:** pull it.
