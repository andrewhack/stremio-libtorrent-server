## My Library offers the file you played

A title the Stremio app plays is now labelled with the file it played, not only with the video, and
its page offers exactly that file once it is complete — never another episode, or a sample, in its
place. Titles learned before this release pick their file up the next time they play.

An episode page no longer offers a finished sample or subtitle while the episode itself is still
arriving, and a pack whose only complete episode is not its largest file now lists it on its card.
The library also lists the other video types the server streams: `.wmv`, `.mpg`, `.mpeg`, `.flv`
and `.ogv`.
