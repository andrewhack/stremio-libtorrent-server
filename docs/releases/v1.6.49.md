# Next episode after a My Library entry

After an episode played from a **My Library** entry, Stremio's next episode had nothing to play
unless that same torrent held it complete. Stremio asks for it only from the addon that played the
current one.

- An episode's entry now appears while its file is still arriving, or has not been fetched yet,
  marked `streaming from peers`. Playing it fetches that episode only, not the rest of the pack.
- Every torrent of the same show counts as one release, so the next episode plays from whichever
  of them holds it. A copy that is all here is listed first.

Films still get an entry only once complete.
