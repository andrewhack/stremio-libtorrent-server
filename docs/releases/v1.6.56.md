# The image build checks what it needs from its base, and .env stays local

- The build fails, naming the program, if the base image no longer provides one the container
  runs (nginx, node, openssl, curl, ffmpeg, ffprobe and a few coreutils). Before, such an image
  built fine and failed at startup.
- `.env.example` lists the variables the compose files read. Copy it to `.env` to keep them in a
  file. `.env` is ignored by git and left out of the build.

**Upgrade:** pull it. Nothing changes at runtime.
