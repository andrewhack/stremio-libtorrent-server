## TV styled subtitles are numbered as the stock server numbers them

The stock server answers a TV's styled-subtitle requests since version 4.22.0, and numbers each
track by its number in the Matroska file. This server numbered them one lower. TV players since
stremio-video 0.0.99 match each styled track to the TV's own entry for the same track by that number,
so a mismatch could hide or select the wrong language. Tracks are now numbered as stock does.

**Upgrade:** pull it.
