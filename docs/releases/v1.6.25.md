## "My Library" names a single file, too

In a title's stream list, the **My Library** row named its file only when the torrent was a season
pack; a standalone episode or film showed just its size, so two copies of one title could only be
told apart by that number. Every row now names the file it will play, as the other sources do —
including a file the server lists from disk after a restart.

**Upgrade:** pull it.
