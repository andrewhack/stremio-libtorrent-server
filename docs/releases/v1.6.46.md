## The server remembers its DHT peers across restarts

The server is meant to save the DHT routing table it learns, so a restart can rejoin the network on
its own when the well-known bootstrap servers cannot be reached. Every save failed without an error
message, so the table was never written. It is now saved every 30 seconds and when the server stops,
and a server started from it rejoins the DHT with the bootstrap servers unreachable.
