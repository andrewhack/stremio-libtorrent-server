## Turn automatic router port-mapping on or off

`STREMIOSRV_ENABLE_UPNP` was in the configuration but never reached the engine, so the server always
asked the router to open its BitTorrent port over UPnP and NAT-PMP. The flag now works: set it to
`false` and both mappers stay off — useful when you forward the port yourself, forward nothing on
purpose, or tunnel the server's traffic, so it stops poking the router for a mapping it does not
need. The default is unchanged: port-mapping stays on, and peer discovery is untouched either way.

**Upgrade:** pull it.
