## Every audio track in a transcoded stream

A transcoded stream carried only the file's first audio track, so a film with several languages
lost all but one in the web player. Every track is now offered and the player can switch between
them, with the file's own default track selected first. Up to 8 tracks, each as stereo AAC. Files
with a single audio track are transcoded exactly as before.
