# Two players on one file share one transcode

Every play that goes through the transcoder started its own encode, so reloading the player or
opening the same file on a second device ran a second full encode beside the first until the
server noticed the first was no longer read.

- A play that needs exactly what a running transcode is producing (the same file, converted the
  same way) now reads that one instead of starting another.
- The transcode stops when the last player reading it stops, or when none has asked for it for a
  while, as before.

**Upgrade:** pull it.
