## Streams that leave the file choice to the server now play

**Torrent engine** — before streaming, the player asks the server to start the torrent and pick
the file (`POST /<infohash>/create`) whenever an addon's stream lists its own trackers or leaves
out the file index. The server had no such route, so those streams never started; for some addons
that was every stream. It now answers as the stock server does: the requested episode, else the
largest media file. The `-1` index that app-built links use for the same streams works too, and
trackers an addon supplies now reach the engine instead of being dropped. Reported as
[#3](https://github.com/andrewhack/stremio-libtorrent-server/issues/3).

**Upgrade:** pull it. No configuration changes.
