## The addon install link is at the top of the library page now

`STREMIOSRV_LIBRARY_UI` is off by default and this release changes nothing else.

The panel holding the addon's install URL was the last section on the page, below every shelf the
library renders. That ordering only worked on an empty server: the sections above it grow without
limit as titles accumulate, so on any real library the one control you need to *set the feature up*
sits behind a scroll that gets longer the longer you use it — and it is one-time setup, not
something you come back to.

It is first now, above Add. The README's install steps say "at the top" to match.

**Upgrade:** pull it. No configuration changes and no route changes.
