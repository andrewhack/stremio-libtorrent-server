# A transcode that turns a player away says so in the log

Two of the ways a transcoded play can fail before it starts left nothing in the log: ffprobe not
answering, and an encode that wrote no playlist in time. The player showed an error or a play that
never began, and the server had no record of it.

- Each of those 504s now logs one `[transcode]` line saying which it was. A torrent is named by
  infohash and file index, any other source only as external, without its URL.

**Upgrade:** pull it.
