## Keep the streaming-server URL you pick

The bundled web player put the seeded streaming-server URL (`SERVER_URL`) back every few seconds and
reloaded the page, so a different URL picked in its settings never stuck — and without `SERVER_URL`
a browser on another machine was held on `127.0.0.1:11470`. The player now takes the seeded URL on a
first visit and keeps whatever you pick after that. Changing `SERVER_URL` applies the new URL once,
and a server you saved stays in the list.

**Upgrade:** pull it. A browser that already has the player picks up the change on its next visit.
